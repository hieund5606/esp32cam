# Smoke Detector iOS App

Ứng dụng iOS giám sát hệ thống phát hiện khói thuốc lá dùng ESP32-S3 + ESP32-CAM.

## Yêu cầu

- **Node.js 18+**
- **macOS** (để build iOS) HOẶC **Codemagic** (cloud build)
- **Xcode 15+** (nếu build local)
- **Apple Developer Account** (nếu muốn cài lâu dài)

## Cài đặt

```bash
npm install
npx cap add ios
npx cap sync
